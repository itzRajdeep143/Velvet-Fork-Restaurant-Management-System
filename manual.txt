3. HOW TO RUN THE PROJECT (EASY METHOD)
================================================================================

Step 1: Open terminal

Step 2: Go to project folder:

  cd /home/niks_2801/Documents/restaurant-webapp

Step 3: Make start script executable (only first time):

  chmod +x start.sh

Step 4: Run the project:

  ./start.sh

Step 5: Wait until you see message like:

  Running on http://127.0.0.1:5000

Step 6: Open browser and visit:

  Website     : http://localhost:5000
  Admin Panel : http://localhost:5000/admin.html

IMPORTANT:
  - Do NOT open index.html directly by double-clicking.
  - Always run through Flask server URL (http://localhost:5000).

================================================================================
4. HOW TO RUN THE PROJECT (MANUAL METHOD)
================================================================================

If start.sh does not work, use these commands:

  cd /home/niks_2801/Documents/restaurant-webapp
  python3 -m venv venv
  ./venv/bin/pip install -r backend/requirements.txt
  ./venv/bin/python backend/app.py

Then open browser:

  http://localhost:5000

================================================================================
5. HOW TO STOP THE SERVER
================================================================================

In the terminal where server is running, press:

  CTRL + C

7. HOW TO USE THE WEBSITE (USER SIDE)
================================================================================

1) Browse menu items and special burgers
2) Use search and category filters
3) Click "Add to Cart" for items
4) Open cart and click "Checkout"

6) Use "Book a Table" section for reservations
7) Switch light/dark theme using moon/sun button

All orders and reservations are saved in database automatically.

10. COMMON PROBLEMS AND SOLUTIONS
================================================================================

Problem: "python3: command not found"
Solution: Install Python 3 on your system.

Problem: Menu not loading / API error shown
Solution:
  - Make sure server is running (./start.sh)
  - Open only http://localhost:5000 (not file:// path)

Problem: Port already in use
Solution:
  - Stop old server using CTRL + C
  - Or run on different port:
      PORT=5001 ./venv/bin/python backend/app.py
    Then open http://localhost:5001

Problem: pip install permission error
Solution:
  - Use virtual environment method shown in Section 4
  - Do not install packages system-wide

Problem: Admin login failed
Solution:
  - Use password: admin123
  - Ensure backend server is running

Main modules:
  1. Customer website (menu, cart, checkout, reservation)
  2. Admin dashboard (manage orders and reservations)
  3. REST API + Database integration

This follows modern 3-tier web application architecture.
